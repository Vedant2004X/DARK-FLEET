## Data semantics preserved

- Historical vessel-level anomaly outputs remain separate from recent/high-resolution FLAG-grouped grid records.
- Grid records are hourly grid-cell aggregates, not individual vessel positions or MMSI identities.
- AIS `vesselIDs` and SAR `vesselIDs` values are aggregate counts in a grid cell, not identity fields.
- Candidate scores remain heuristic rankings, not calibrated probabilities.
- The Isolation Forest still requires independent labels and holdout validation before accuracy claims.
